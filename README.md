# Laura Douglass — Portfolio

This repository contains a starter Next.js + TypeScript + Tailwind portfolio for Laura Douglass.

What I created:
- Next.js app with TypeScript
- Tailwind CSS configured
- Home page with hero, experience, projects and contact sections
- Data file with the project links you provided

Next steps for you:
1. Replace the placeholder profile image at public/profile-placeholder.svg with your uploaded photo (name it `/public/profile.jpg`) and update the image import in `pages/index.tsx` if needed.
2. Add `resume.pdf` to the `public/` folder so the "Download CV" button works.
3. Review and edit copy in `pages/index.tsx` and `data/projects.ts`.

To run locally:

1. Install dependencies: `npm install` (or `pnpm`/`yarn`)
2. Run the dev server: `npm run dev`

To deploy: connect the repo to Vercel and set the root to the repository — Vercel will detect Next.js and use default settings.
